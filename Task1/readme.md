## Проблемные места

| № | Проблемное место                          | Описание                                                                                                                      |
|---|-------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| 1 | Перегруженный и устаревший DWH            | Вся работа завязана на один SQL Server DWH                                                                                    |
| 2 | Сложные и долгие отчёты                   | Долгое построение отчетов                                                                                                     |
| 3 | Высокие риски из-за устаревших технологий | DWH построен на SQL Server 2008, Power Builder считается устаревшим. Поэтому возникают проблемы с поддержкой и сопровождением |
| 4 | Привязанность к legacy                    | Power Builder работает с DWH, поэтому есть сложности с обновлением и масштабированием                                         |
| 5 | Сложность масштабирования                 | С ростом данных SQL Server DWH не масштабируется горизонтально                                                                |

## Приоритизация выявленных проблем

| Приоритет                   | Проблемное место                          | Аргументация                                                                 |
|-----------------------------|-------------------------------------------|------------------------------------------------------------------------------|
| Must have (обязательно)     | Перегруженный и устаревший DWH            | Нужно разгрузить DWH, чтобы ускорить построение отчётов                      |
| Must have (обязательно)     | Сложные и долгие отчёты                   | Необходимо оперативно предоставлять информацию для принятия решения бизнесом |
| Should have (желательно)    | Привязанность к legacy                    | Усложняет развитие                                                           |
| Could have (можно улучшить) | Высокие риски из-за устаревших технологий | Как можно раньше обновить, пока есть поддержка                               |
| Could have (можно улучшить) | Сложность масштабирования                 | В будущем может стать узким горлышком при поддержке более высокой нагрузки   |
